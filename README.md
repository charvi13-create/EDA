# Amazon Prime Video – Exploratory Data Analysis (EDA)

## Project Overview
This project performs Exploratory Data Analysis on Amazon Prime Video movies and TV shows using Python.

## Datasets
- `titles.csv` – Contains information about titles, genres, release years, runtime and ratings.
- `credits.csv` – Contains information about actors, directors and other credited contributors.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Project Workflow
1. Data loading and inspection
2. Data cleaning and preprocessing
3. Exploratory Data Analysis
4. Data visualization
5. Business insights and recommendations

## Visualizations
The project includes 15 visualizations exploring content distribution, release trends, genres, production countries, ratings, runtime, popularity and correlations.
